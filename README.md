# TataChatSDK · 塔塔聊天

塔塔聊天是面向 Flutter 应用的端到端加密聊天 SDK，帮助产品接入私聊、群聊、文件分享和一对一语音、视频通话。

- **私聊与群聊**：支持文字、表情、贴纸、图片、视频、语音和文件消息。
- **隐私保护**：消息与附件采用端到端加密，聊天记录保存在客户端。
- **可靠收发**：提供离线消息同步、失败重试、去重和发送状态管理。
- **完整聊天界面**：提供会话列表、聊天页面、消息输入、媒体预览与搜索能力。
- **灵活接入**：宿主应用提供账户和产品配置，复用同一套聊天能力，并可对接自部署聊天服务。
